# План 2. Проверка анкет

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ревьюер входит по ссылке на почту, проходит анкету по блокам, отмечает проблемные поля с комментарием, возвращает на правку или принимает — а заполняющий видит только отмеченное.

**Architecture:** Модуль `review` владеет подтверждением блоков и замечаниями; `submissions/transitions` дополняется переходами `submitted → changes_requested → approved`. При принятии классифицирующие поля копируются в `lounges` — единственное место такой записи.

**Tech Stack:** тот же, что в плане 1. Добавляются `nodemailer` для писем и таблица `sessions` для входа команды.

**Предусловие:** план 1 выполнен полностью, `npm test && npm run typecheck && npm run build && npm run e2e` зелёные.

## Global Constraints

- Всё из «Global Constraints» плана 1 действует и здесь.
- Проверяет один человек. Разделения по ролям нет, `reviewer_id` — просто отметка, кто взял анкету.
- Замечание вешается на то, что заполняющий видит как один вопрос: 67 ключей плоских полей, 58 ключей позиций услуг (позиция целиком, не отдельный атрибут), ключи слотов фотографий. Претензия к конкретному атрибуту выражается текстом комментария.
- Анкета принимается только когда подтверждены все **27** блоков и нет ни одного незакрытого замечания.
- Подтверждение блока переживает возврат на правку: при повторной отправке перепроверяется только исправленное.
- Оператор лаунжа по токену не может ни подтверждать блоки, ни менять `operational_status`.
- **Ссылка для заполнения — это и есть доступ к анкете.** При возврате на правку оператору выдаётся **новая** ссылка (`issueFillToken`), а истёкшие ссылки не оживляются никогда. Продление удалено: раз сырой токен не хранится, конкретную утёкшую ссылку нельзя отозвать выборочно, поэтому оживление старых токенов возвращало бы доступ тому, кто держит мёртвую ссылку. Если ссылка на черновике истекла до отправки, восстановление — тоже выдача новой; кнопка «переслать ссылку» в кабинете нужна и добавляется в Task 6 этого плана.
- **Порядок блокировок: сначала `submissions`, потом дочерние таблицы.** `saveFieldValue`/`saveServiceValue` внутри транзакции берут `FOR UPDATE` на строку анкеты и только затем пишут в `field_values`/`service_values`. Любая транзакция, меняющая статус анкеты, должна трогать `submissions` первой или не трогать дочерние таблицы вовсе. Обратный порядок даёт взаимную блокировку.
- **Границы модулей из спецификации соблюдаются:** `review` владеет таблицами `field_flags` и `block_reviews`, `submissions` в них не заглядывает. Там, где нужны оба модуля сразу (правка отмеченного ответа снимает замечание), их согласует слой серверных действий — он и так зависит от всего.

```ts
import { randomBytes, createHash } from 'node:crypto'
import { and, eq, gt, isNull, sql } from 'drizzle-orm'
import type { Localized } from '@/form-schema'
import type { Db } from '@/db/types'
import { teamMembers, loginTokens, sessions } from '@/db/schema'

const LOGIN_TTL_MINUTES = 20
const SESSION_TTL_DAYS = 30

const hash = (token: string): string =>
  createHash('sha256').update(token).digest('hex')

const minutesFromNow = (minutes: number): Date =>
  new Date(Date.now() + minutes * 60 * 1000)

const daysFromNow = (days: number): Date =>
  new Date(Date.now() + days * 24 * 60 * 60 * 1000)

export async function requestLogin(
  db: Db,
  email: string,
): Promise<{ token: string } | { error: Localized }> {
  // Почта сверяется без учёта регистра: люди пишут её как придётся.
  const rows = await db
    .select({ id: teamMembers.id })
    .from(teamMembers)
    .where(sql`lower(${teamMembers.email}) = ${email.trim().toLowerCase()}`)
    .limit(1)

  const member = rows[0]
  if (!member) {
    return {
      error: {
        en: 'This address is not on the team',
        ru: 'Этой почты нет в команде',
      },
    }
  }

  const token = randomBytes(32).toString('base64url')
  await db.insert(loginTokens).values({
    memberId: member.id,
    tokenHash: hash(token),
    expiresAt: minutesFromNow(LOGIN_TTL_MINUTES),
  })

  return { token }
}

export async function consumeLoginToken(
  db: Db,
  token: string,
): Promise<{ sessionId: string; memberId: string } | null> {
  const rows = await db
    .select({ id: loginTokens.id, memberId: loginTokens.memberId })
    .from(loginTokens)
    .where(
      and(
        eq(loginTokens.tokenHash, hash(token)),
        gt(loginTokens.expiresAt, new Date()),
        isNull(loginTokens.usedAt),
      ),
    )
    .limit(1)

  const row = rows[0]
  if (!row) return null

  await db
    .update(loginTokens)
    .set({ usedAt: new Date() })
    .where(eq(loginTokens.id, row.id))

  const [session] = await db
    .insert(sessions)
    .values({ memberId: row.memberId, expiresAt: daysFromNow(SESSION_TTL_DAYS) })
    .returning()

  return { sessionId: session!.id, memberId: row.memberId }
}

export async function resolveSession(
  db: Db,
  sessionId: string,
): Promise<{ memberId: string; email: string } | null> {
  const rows = await db
    .select({ memberId: teamMembers.id, email: teamMembers.email })
    .from(sessions)
    .innerJoin(teamMembers, eq(sessions.memberId, teamMembers.id))
    .where(and(eq(sessions.id, sessionId), gt(sessions.expiresAt, new Date())))
    .limit(1)

  return rows[0] ?? null
}

export async function endSession(db: Db, sessionId: string): Promise<void> {
  await db.delete(sessions).where(eq(sessions.id, sessionId))
}
```

```ts
import { and, eq, isNull } from 'drizzle-orm'
import type { Localized } from '@/form-schema'
import { FIELDS, SERVICE_ITEMS, SERVICE_GROUPS, PHOTO_SLOTS } from '@/form-schema'
import type { Db, Tx } from '@/db/types'
import { fieldFlags, blockReviews } from '@/db/schema'

export type FlagReason = 'empty' | 'needs_detail' | 'contradicts' | 'wrong_format'

export type FlagRow = {
  id: string
  fieldKey: string
  reason: FlagReason | null
  comment: string
}

export type FlagResult = { ok: true } | { ok: false; error: Localized }

/**
 * Замечание адресует то, что заполняющий видит как один вопрос: поле,
 * позицию услуг целиком или слот фотографии. Претензия к отдельному
 * атрибуту позиции выражается текстом комментария — на возврате всё равно
 * открывается вся позиция.
 */
const FLAGGABLE: ReadonlySet<string> = new Set([
  ...FIELDS.map((f) => f.key),
  ...SERVICE_ITEMS.map((i) => i.key),
  ...PHOTO_SLOTS.map((s) => s.key),
])

export function isFlaggableKey(key: string): boolean {
  return FLAGGABLE.has(key)
}

export async function raiseFlag(
  db: Db,
  input: {
    submissionId: string
    fieldKey: string
    reason: FlagReason | null
    comment: string
    reviewer: string
  },
): Promise<FlagResult> {
  if (!isFlaggableKey(input.fieldKey)) {
    return { ok: false, error: { en: 'Unknown field', ru: 'Неизвестное поле' } }
  }

  const comment = input.comment.trim()
  if (comment === '') {
    return {
      ok: false,
      error: { en: 'Say what is wrong', ru: 'Напишите, что не так' },
    }
  }

  // Одно открытое замечание на поле: повторное уточняет прежнее.
  await db
    .delete(fieldFlags)
    .where(
      and(
        eq(fieldFlags.submissionId, input.submissionId),
        eq(fieldFlags.fieldKey, input.fieldKey),
        isNull(fieldFlags.resolvedAt),
      ),
    )

  await db.insert(fieldFlags).values({
    submissionId: input.submissionId,
    fieldKey: input.fieldKey,
    reason: input.reason,
    comment,
    createdBy: input.reviewer,
  })

  return { ok: true }
}

export async function resolveFlag(db: Db, flagId: string): Promise<void> {
  await db
    .update(fieldFlags)
    .set({ resolvedAt: new Date() })
    .where(eq(fieldFlags.id, flagId))
}

/** Блок, за который отвечает отмеченный ключ. */
export function blockKeyOf(key: string): string | null {
  const field = FIELDS.find((f) => f.key === key)
  if (field) return field.block

  const item = SERVICE_ITEMS.find((i) => i.key === key)
  if (item) return SERVICE_GROUPS.find((g) => g.key === item.group)?.block ?? null

  return PHOTO_SLOTS.some((s) => s.key === key) ? 'photos' : null
}

/**
 * Снимает открытое замечание по ключу и подтверждение его блока: исправленное
 * ревьюер должен посмотреть заново, а остальные блоки остаются подтверждёнными.
 * Возвращает `true`, если замечание было.
 */
export async function clearFlagsFor(
  db: Db,
  submissionId: string,
  key: string,
): Promise<boolean> {
  const cleared = await db
    .update(fieldFlags)
    .set({ resolvedAt: new Date() })
    .where(
      and(
        eq(fieldFlags.submissionId, submissionId),
        eq(fieldFlags.fieldKey, key),
        isNull(fieldFlags.resolvedAt),
      ),
    )
    .returning({ id: fieldFlags.id })

  if (cleared.length === 0) return false

  const blockKey = blockKeyOf(key)
  if (blockKey) {
    await db
      .delete(blockReviews)
      .where(
        and(
          eq(blockReviews.submissionId, submissionId),
          eq(blockReviews.blockKey, blockKey),
        ),
      )
  }

  return true
}

/**
 * `Db | Tx`, not `Db`: Task 4's `approveSubmission`/`requestChanges` must
 * read open flags from *inside* their own transaction (locked on
 * `submissions`), the same reason `missingItems` in
 * `src/submissions/completeness.ts` already takes `Db | Tx` rather than
 * just `Db` — a read that also needs to run under an existing transaction's
 * lock cannot be typed to accept only a fresh, unlocked connection.
 */
export async function openFlags(db: Db | Tx, submissionId: string): Promise<FlagRow[]> {
  const rows = await db
    .select({
      id: fieldFlags.id,
      fieldKey: fieldFlags.fieldKey,
      reason: fieldFlags.reason,
      comment: fieldFlags.comment,
    })
    .from(fieldFlags)
    .where(
      and(eq(fieldFlags.submissionId, submissionId), isNull(fieldFlags.resolvedAt)),
    )

  return rows.map((row) => ({
    id: row.id,
    fieldKey: row.fieldKey,
    reason: row.reason as FlagReason | null,
    comment: row.comment,
  }))
}

import { and, eq } from 'drizzle-orm'
import type { Localized } from '@/form-schema'
import { BLOCKS, FIELDS, SERVICE_GROUPS, SERVICE_ITEMS, PHOTO_SLOTS } from '@/form-schema'
import type { Db, Tx } from '@/db/types'
import { blockReviews } from '@/db/schema'
import { openFlags } from './flags'

export type BlockState = {
  blockKey: string
  confirmed: boolean
  openFlagCount: number
}

export type ConfirmResult = { ok: true } | { ok: false; error: Localized }

/** Ключи, за которые отвечает блок — по ним считаются его замечания. */
export function keysOfBlock(blockKey: string): string[] {
  if (blockKey === 'photos') return PHOTO_SLOTS.map((s) => s.key)

  const fieldKeys = FIELDS.filter((f) => f.block === blockKey).map((f) => f.key)
  if (fieldKeys.length > 0) return fieldKeys

  const groups = SERVICE_GROUPS.filter((g) => g.block === blockKey).map((g) => g.key)
  return SERVICE_ITEMS.filter((i) => groups.includes(i.group)).map((i) => i.key)
}

export async function confirmBlock(
  db: Db,
  input: { submissionId: string; blockKey: string; reviewer: string },
): Promise<ConfirmResult> {
  const keys = new Set(keysOfBlock(input.blockKey))
  if (keys.size === 0) {
    return { ok: false, error: { en: 'Unknown block', ru: 'Неизвестный блок' } }
  }

  const flags = await openFlags(db, input.submissionId)
  const inThisBlock = flags.filter((f) => keys.has(f.fieldKey))
  if (inThisBlock.length > 0) {
    return {
      ok: false,
      error: {
        en: 'Resolve the flags in this block first',
        ru: 'Сначала снимите замечания в этом блоке',
      },
    }
  }

  await db
    .insert(blockReviews)
    .values({
      submissionId: input.submissionId,
      blockKey: input.blockKey,
      confirmedBy: input.reviewer,
    })
    .onConflictDoUpdate({
      target: [blockReviews.submissionId, blockReviews.blockKey],
      set: { confirmedBy: input.reviewer, confirmedAt: new Date() },
    })

  return { ok: true }
}

export async function unconfirmBlock(
  db: Db,
  input: { submissionId: string; blockKey: string },
): Promise<void> {
  await db
    .delete(blockReviews)
    .where(
      and(
        eq(blockReviews.submissionId, input.submissionId),
        eq(blockReviews.blockKey, input.blockKey),
      ),
    )
}

/**
 * `Db | Tx`, same reason as `openFlags` above: `approveSubmission` (Task 4)
 * checks block confirmation from inside its own locked transaction.
 */
export async function blockProgress(
  db: Db | Tx,
  submissionId: string,
): Promise<BlockState[]> {
  const confirmed = await db
    .select({ blockKey: blockReviews.blockKey })
    .from(blockReviews)
    .where(eq(blockReviews.submissionId, submissionId))
  const confirmedKeys = new Set(confirmed.map((row) => row.blockKey))

  const flags = await openFlags(db, submissionId)

  return BLOCKS.map((block) => {
    const keys = new Set(keysOfBlock(block.key))
    return {
      blockKey: block.key,
      confirmed: confirmedKeys.has(block.key),
      openFlagCount: flags.filter((f) => keys.has(f.fieldKey)).length,
    }
  })
}
```

import type { Db, Tx } from '@/db/types'
import { submissions, lounges, events } from '@/db/schema'
import type { TransitionResult } from '@/submissions/transitions'
import { loadSubmissionValues } from '@/submissions/values'
import { openFlags } from './flags'
import { blockProgress } from './blocks'

const fail = (en: string, ru: string): TransitionResult => ({
  ok: false,
  error: { en, ru },
})

export type ClassifyingFields = {
  terminal: string | null
  terminalType: string | null
  zone: string[] | null
  airsideLandside: string | null
}

function optionOf(value: unknown): string | null {
  if (typeof value === 'object' && value !== null && 'option' in value) {
    const option = (value as { option: unknown }).option
    return typeof option === 'string' && option !== '' ? option : null
  }
  return null
}

/**
 * Характеристики, по которым фильтруются реестр и выгрузка. Копируются
 * в `lounges` только при принятии — реестр показывает подтверждённые данные,
 * а не то, что кто-то печатает в черновике.
 */
export function classifyingFieldsFrom(
  values: Record<string, unknown>,
): ClassifyingFields {
  const zone = values['III.6.6']
  return {
    terminal: optionOf(values['III.6.2']),
    terminalType: optionOf(values['III.6.1']),
    zone: Array.isArray(zone) && zone.length > 0 ? (zone as string[]) : null,
    airsideLandside: optionOf(values['III.6.4']),
  }
}

/**
 * Читает статус анкеты с `FOR UPDATE` — как `assertEditable` в
 * `submissions/values.ts` и как `submitSubmission` в `transitions.ts`. Обе
 * функции этого модуля меняют статус и пишут событие, поэтому обе целиком
 * идут в одной транзакции с блокировкой строки `submissions` в начале —
 * иначе конкурентный вызов submit/approve/request-changes ничем не
 * сериализуется, и падение между UPDATE и INSERT рвёт инвариант «каждая
 * смена статуса пишет событие» (тот же класс дефекта, что был закрыт в
 * плане 1, Task 10, фикс-раунд 1).
 */
async function lockedStatus(tx: Tx, submissionId: string): Promise<string | null> {
  const rows = await tx
    .select({ status: submissions.status })
    .from(submissions)
    .where(eq(submissions.id, submissionId))
    .for('update')
    .limit(1)
  return rows[0]?.status ?? null
}

export async function requestChanges(
  db: Db,
  input: { submissionId: string; reviewer: string },
): Promise<TransitionResult> {
  return db.transaction(async (tx) => {
    const status = await lockedStatus(tx, input.submissionId)
    if (!status) return fail('Submission not found', 'Анкета не найдена')
    if (status !== 'submitted') {
      return fail('Submission is not under review', 'Анкета не на проверке')
    }

    const flags = await openFlags(tx, input.submissionId)
    if (flags.length === 0) {
      return fail(
        'Flag at least one answer before sending it back',
        'Отметьте хотя бы один ответ, прежде чем возвращать',
      )
    }

    const now = new Date()
    await tx
      .update(submissions)
      .set({ status: 'changes_requested', reviewerId: input.reviewer, statusChangedAt: now })
      .where(eq(submissions.id, input.submissionId))

    await tx.insert(events).values({
      submissionId: input.submissionId,
      actor: input.reviewer,
      action: 'changes_requested',
      payload: { flagCount: flags.length },
    })

    return { ok: true, status: 'changes_requested' }
  })
}

export async function approveSubmission(
  db: Db,
  input: { submissionId: string; reviewer: string },
): Promise<TransitionResult> {
  return db.transaction(async (tx) => {
    const status = await lockedStatus(tx, input.submissionId)
    if (!status) return fail('Submission not found', 'Анкета не найдена')
    if (status !== 'submitted') {
      return fail('Submission is not under review', 'Анкета не на проверке')
    }

    const flags = await openFlags(tx, input.submissionId)
    if (flags.length > 0) {
      return fail(
        `${flags.length} flag(s) still open`,
        `Открытых замечаний: ${flags.length}`,
      )
    }

    const progress = await blockProgress(tx, input.submissionId)
    const pending = progress.filter((block) => !block.confirmed)
    if (pending.length > 0) {
      return fail(
        `${pending.length} block(s) not confirmed`,
        `Не подтверждено блоков: ${pending.length}`,
      )
    }

    const rows = await tx
      .select({ loungeId: submissions.loungeId })
      .from(submissions)
      .where(eq(submissions.id, input.submissionId))
      .limit(1)
    const loungeId = rows[0]?.loungeId
    if (!loungeId) return fail('Submission not found', 'Анкета не найдена')

    const values = await loadSubmissionValues(tx, input.submissionId)
    const classifying = classifyingFieldsFrom(values.fields)

    const now = new Date()
    await tx
      .update(submissions)
      .set({ status: 'approved', reviewerId: input.reviewer, decidedAt: now, statusChangedAt: now })
      .where(eq(submissions.id, input.submissionId))

    await tx.update(lounges).set(classifying).where(eq(lounges.id, loungeId))

    await tx.insert(events).values({
      loungeId,
      submissionId: input.submissionId,
      actor: input.reviewer,
      action: 'approved',
      payload: { classifying },
    })

    return { ok: true, status: 'approved' }
  })
}

import { createTransport } from 'nodemailer'
import type { OutgoingMail } from './messages'

export type Mailer = { send(message: OutgoingMail): Promise<void> }

/**
 * Без SMTP_URL письма печатаются в консоль. Локальная разработка не должна
 * требовать почтового сервера, а молчаливое проглатывание письма прячет
 * ошибку до продакшена.
 */
export function createMailer(): Mailer {
  const url = process.env.SMTP_URL
  const from = process.env.MAIL_FROM ?? 'noreply@example.com'

  if (!url) {
    return {
      async send(message) {
        process.stdout.write(
          `\n[mail] → ${message.to}\n[mail] ${message.subject}\n${message.text}\n\n`,
        )
      },
    }
  }

  const transport = createTransport(url)
  return {
    async send(message) {
      await transport.sendMail({ from, ...message })
    },
  }
}

import { and, eq } from 'drizzle-orm'
import type { Localized } from '@/form-schema'
import { db } from '@/db/client'
import { requireSession } from '@/access/session'
import { raiseFlag, resolveFlag, openFlags, type FlagReason } from '@/review/flags'
import { confirmBlock } from '@/review/blocks'

import { submissions, lounges, fieldValues } from '@/db/schema'
import { createMailer } from '@/notify/mailer'

/**
 * `error` несёт весь `Localized`, а не заранее выбранную строку — то же
 * решение, что и в `src/app/f/[token]/actions.ts` (см. его собственный
 * комментарий): у серверного действия нет надёжного понятия «локаль
 * вызывающего», а клиент уже умеет выбирать через `pick()`. Раньше здесь
 * стояло `{ ok: boolean; error?: string }` с `result.error.ru` на каждом
 * отказе — тот самый дефект (Important, финальный обзор всей ветки), который
 * фикс-раунд уже закрыл на стороне заполняющего; заводить его заново на
 * стороне ревьюера было бы неправильно.
 */
type ActionResult = { ok: true } | { ok: false; error: Localized }

export async function flagAction(
  submissionId: string,
  fieldKey: string,
  reason: FlagReason | null,
  comment: string,
): Promise<ActionResult> {
  const session = await requireSession()
  const result = await raiseFlag(db(), {
    submissionId, fieldKey, reason, comment, reviewer: session.email,
  })
  revalidatePath(`/admin/s/${submissionId}`)
  return result.ok ? { ok: true } : { ok: false, error: result.error }
}

export async function unflagAction(
  submissionId: string,
  flagId: string,
): Promise<ActionResult> {
  await requireSession()
  await resolveFlag(db(), flagId)
  revalidatePath(`/admin/s/${submissionId}`)
  return { ok: true }
}

export async function confirmBlockAction(
  submissionId: string,
  blockKey: string,
): Promise<ActionResult> {
  const session = await requireSession()
  const result = await confirmBlock(db(), {
    submissionId, blockKey, reviewer: session.email,
  })
  revalidatePath(`/admin/s/${submissionId}`)
  return result.ok ? { ok: true } : { ok: false, error: result.error }
}

async function contactEmail(submissionId: string): Promise<string | null> {
  // II.1.3 — Email Address - Lounge Operations Manager
  const rows = await db()
    .select({ value: fieldValues.value })
    .from(fieldValues)
    .where(
      and(
        eq(fieldValues.submissionId, submissionId),
        eq(fieldValues.fieldKey, 'II.1.3'),
      ),
    )
    .limit(1)

  const value = rows[0]?.value
  return typeof value === 'string' && value.includes('@') ? value : null
}

async function loungeName(submissionId: string): Promise<string> {
  const rows = await db()
    .select({ name: lounges.name })
    .from(submissions)
    .innerJoin(lounges, eq(submissions.loungeId, lounges.id))
    .where(eq(submissions.id, submissionId))
    .limit(1)
  return rows[0]?.name ?? 'Lounge'
}

export async function requestChangesAction(
  submissionId: string,
): Promise<ActionResult> {
  const session = await requireSession()
  const flags = await openFlags(db(), submissionId)
  const result = await requestChanges(db(), { submissionId, reviewer: session.email })
  if (!result.ok) return { ok: false, error: result.error }

  const to = await contactEmail(submissionId)
  if (to) {
    const { token } = await issueFillToken(db(), { submissionId, ttlDays: 30 })
    const base = process.env.APP_URL ?? 'http://localhost:3000'
    await createMailer().send(
      changesRequestedMail({
        to,
        loungeName: await loungeName(submissionId),
        fillUrl: `${base}/f/${token}`,
        flagCount: flags.length,
      }),
    )
  }

  revalidatePath(`/admin/s/${submissionId}`)
  return { ok: true }
}

/**
 * Переслать оператору свежую ссылку. Единственный способ восстановить доступ:
 * истёкшие ссылки не оживляются, а конкретную утёкшую отозвать нельзя, потому
 * что сырой токен не хранится.
 */
export async function resendFillLinkAction(
  submissionId: string,
): Promise<ActionResult> {
  await requireSession()

  const to = await contactEmail(submissionId)
  if (!to) {
    return {
      ok: false,
      error: {
        en: 'This submission has no contact email (II.1.3)',
        ru: 'У анкеты нет контактной почты (II.1.3)',
      },
    }
  }

  const { token } = await issueFillToken(db(), { submissionId, ttlDays: 30 })
  const base = process.env.APP_URL ?? 'http://localhost:3000'
  await createMailer().send(
    changesRequestedMail({
      to,
      loungeName: await loungeName(submissionId),
      fillUrl: `${base}/f/${token}`,
      flagCount: (await openFlags(db(), submissionId)).length,
    }),
  )

  return { ok: true }
}

export async function approveAction(submissionId: string): Promise<ActionResult> {
  const session = await requireSession()
  const result = await approveSubmission(db(), { submissionId, reviewer: session.email })
  if (!result.ok) return { ok: false, error: result.error }

  const to = await contactEmail(submissionId)
  if (to) {
    await createMailer().send(
      approvedMail({ to, loungeName: await loungeName(submissionId) }),
    )
  }

  revalidatePath(`/admin/s/${submissionId}`)
  return { ok: true }
}

/** Плоское представление значений для показа ревьюеру. */
export function renderValues(input: {
  fields: Record<string, unknown>
  services: Record<string, { available: string | null; chargeType: string | null; price: number | null; currency: string | null }>
  photos: Record<string, string[]>
  locale: 'en' | 'ru'
}): Record<string, { label: string; value: string }> {
  const out: Record<string, { label: string; value: string }> = {}

  for (const field of FIELDS) {
    const raw = input.fields[field.key]
    out[field.key] = {
      label: field.label[input.locale],
      value: formatValue(raw),
    }
  }

  for (const item of SERVICE_ITEMS) {
    const value = input.services[item.key]
    const parts = [
      value?.available ?? '—',
      value?.chargeType ?? null,
      value?.price !== null && value?.price !== undefined
        ? `${value.price} ${value.currency ?? ''}`.trim()
        : null,
    ].filter(Boolean)
    out[item.key] = { label: item.label[input.locale], value: parts.join(' · ') }
  }

  for (const slot of PHOTO_SLOTS) {
    const urls = input.photos[slot.key] ?? []
    out[slot.key] = {
      label: slot.label[input.locale],
      value: urls.length === 0 ? '—' : `${urls.length}`,
    }
  }

  return out
}

function formatValue(raw: unknown): string {
  if (raw === null || raw === undefined || raw === '') return '—'
  if (Array.isArray(raw)) return raw.join(', ')
  if (typeof raw === 'object' && 'option' in raw) {
    const value = raw as { option: string; detail: string | null }
    return value.detail ? `${value.option} — ${value.detail}` : value.option
  }
  if (typeof raw === 'object') {
    return Object.entries(raw as Record<string, unknown>)
      .map(([key, val]) => `${key}: ${String(val)}`)
      .join(', ')
  }
  return String(raw)
}

import { test, expect, type Page } from '@playwright/test'
import { execSync } from 'node:child_process'

/** Печатает одноразовую ссылку входа для указанной почты. Только для локальных тестов. */
import { createDb } from '../src/db/client'
import { requestLogin } from '../src/access/team'

async function main(): Promise<void> {
  const email = process.argv[2]
  const url = process.env.DATABASE_URL
  if (!email) throw new Error('usage: dev-login-link.ts <email>')
  if (!url) throw new Error('DATABASE_URL не задан')

  if (!('token' in result)) throw new Error(result.error.ru)

  const base = process.env.APP_URL ?? 'http://localhost:3000'
  process.stdout.write(`${base}/admin/login/${result.token}\n`)
}

void main()
